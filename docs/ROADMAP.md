# Product Roadmap

## SONORA SongWeaver Roadmap

### Phase 0: Repository Audit & Technical Foundation (Completed)
- [x] TypeScript architecture with Web Audio API and Standard MIDI File binary support.
- [x] Versioned project schema (`ProjectModel`).

### Phase 1: Functional Arrangement Engine (Completed)
- [x] 3 Distinct Concepts: Build, Atmospheric, and Performance.
- [x] Musical Variation Engine with note omission, velocity shaping, fills, and octave shifts.
- [x] Type 1 Standard MIDI File binary parser and writer with round-trip validation.
- [x] Multi-timbral Web Audio synthesis engine with sub-millisecond scheduling.

### Phase 2: Workstation User Interface (Completed)
- [x] Hardware-inspired top bar and transport bar with digital LCD displays.
- [x] DAW arrangement canvas with live playhead, section blocks, track lanes, and mini piano-roll note strokes.
- [x] Arrangement Concepts modal with side-by-side comparison and instant auditioning.
- [x] Section inspector with track activity matrix and isolated section regeneration.
- [x] Natural language command bar with prompt processor.
- [x] Automated Section 19 test runner.

### Phase 3: Audio Analysis & Reference Handling (Completed)
- [x] Spectral flux onset detection.
- [x] Autocorrelation BPM estimation with confidence percentage.
- [x] Peak waveform generation and downbeat calculation.

### Phase 4: Creative Intelligence & Natural Language (Completed)
- [x] Plain-language arrangement commands for section resizing, track muting, energy boosting, and length adjustment.
- [x] Energy contour visualization.

### Phase 5: Ecosystem & Distribution (Active / Next)
- [ ] Direct file drop integration with ChordForge and LoDrum Maker.
- [ ] Soundfont/WAV sample bank loader for user custom instruments.
